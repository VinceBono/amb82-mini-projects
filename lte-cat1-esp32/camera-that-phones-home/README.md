# Camera that phones home

**Status: planned. No code yet, nothing has been run on a board.**

The AMB82-Mini detects a person and hands the alert to this board, which sends a text over LTE. Cut or jam the Wi-Fi and the alert still arrives. The defence half of [fool-the-camera](../../amb82-mini/fool-the-camera/).

- **Needs:** UART link between the two boards, SMS over AT commands, and a SIM with a data plan
