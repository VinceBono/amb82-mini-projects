# Fool the camera

**Status: planned. No code yet, nothing has been run on a board.**

Run the stock person detector, then try to make it miss you with printed patches, clothing and lighting. A scoreboard records which attacks worked.

- **Starts from:** `ObjectDetectionCallback`, MQTT basic connection (examples in the [Ameba Arduino SDK](https://github.com/Ameba-AIoT/ameba-arduino-pro2))
- **To add:** A Python logger on the PC that records the person confidence per attempt.
