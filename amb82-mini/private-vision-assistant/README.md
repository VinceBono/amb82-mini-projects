# Private vision assistant

**Status: planned. No code yet, nothing has been run on a board.**

The board posts a snapshot and a spoken question to a PC on the same network, where a local vision model answers. No frames leave the network.

- **Starts from:** `HTTP Post Image and MP4` (examples in the [Ameba Arduino SDK](https://github.com/Ameba-AIoT/ameba-arduino-pro2))
- **To add:** A small server that hands the image to a local model.
