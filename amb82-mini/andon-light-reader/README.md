# Andon light reader

**Status: planned. No code yet, nothing has been run on a board.**

Point the camera at a machine's stack light and publish red, yellow or green over MQTT. Machine status from equipment with no network port.

- **Starts from:** `RTSP Streaming`, MQTT basic connection (examples in the [Ameba Arduino SDK](https://github.com/Ameba-AIoT/ameba-arduino-pro2))
- **To add:** Colour-region logic on the board. Tested on a bench stack light or a picture of one, never on plant equipment.
